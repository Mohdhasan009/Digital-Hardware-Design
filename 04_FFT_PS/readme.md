# 8-Point FFT on ZYBO (Processing System)

This project implements an **8-point Fast Fourier Transform (FFT)** on the **Processing System (ARM Cortex-A9)** of the **ZYBO (Zynq-7000)** FPGA using the **Xilinx SDK**.

## Tools

* ZYBO (Zynq-7000)
* Xilinx Vivado
* Xilinx SDK
* C

## Project Highlights

* 8-point FFT implementation in software
* Bit-reversal and butterfly computation
* FFT output through the SDK console

## Note

This repository contains the application source code. Platform-specific files (BSP, hardware export, and other SDK-generated files) are not included and should be generated for the target hardware.
