# 8-bit Counter

## Overview

This project implements an 8-bit synchronous binary counter in Verilog.

## Features

- Positive edge-triggered counter
- Synchronous reset
- Clock divider for slow clock generation
- Top-level integration module
- Tested using a Verilog testbench

## Project Structure

```
rtl/
    counter.v
    clock_divider.v
    top_counter.v
    vio_wrapper.v

tb/
    counter_tb.v

images/
```

## Tools Used

- Verilog HDL
- Xilinx Vivado
- Git & GitHub
